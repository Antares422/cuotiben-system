# 界面设计说明

## 概念：红笔批改的练习本

"错题本"本来就是一个实物。界面围绕这个实物来做，而不是通用的白底卡片：

| 实物 | 界面里的体现 |
| :--- | :--- |
| 练习本的纸 | 暖色纸张底 + 极淡的噪点纸纹；表单、详情是带蓝色横线的"纸页"，左侧有红色边距线 |
| 螺旋装订 | 顶部深蓝封面条下沿的一排圆环 |
| 老师的红笔批注 | 错误原因用红色楷体 + 波浪下划线；正确答案用绿色楷体 |
| 作业上盖的章 | "已掌握"是绿色双线章，"未掌握"是红色虚线章，微微倾斜 |
| 贴在本子上的照片 | 原图是带胶带的相框，识别时有一条红色扫描线从上扫到下 |
| 荧光笔 | 页面标题下划着一道黄色荧光 |

## 设计决定

- **字体全部用系统字体栈**：标题用宋体系衬线（`Songti SC` / `STSong` / `Noto Serif CJK SC` / `SimSun`），批注用楷体系（`Kaiti SC` / `KaiTi`），正文用无衬线。
  不引用在线字体，因为应用是单机离线运行的，而中文网页字体动辄几 MB。代价是不同系统上字形略有差异。
- **学科配色**：九个默认学科各有一支固定的"彩笔"色（`src/subject-color.ts`），列表卡片左侧色带、学科标签都用它，一眼分辨；新增学科循环取色。
- **手机优先**：底部导航栏（拇指够得着），顶部只留封面条；桌面端（≥ 760px）导航移到封面条右侧。可点击元素不小于 44px。
- **步骤条**：拍照 → 核对 → 保存，对应 PRD "录入不超过 3 步"；自己手敲题目时也会推进到"核对"。
- **动效**：页面切换淡入上移，列表卡片依次浮现，照片落在纸上；立体按钮按下会下沉。系统开启"减少动画"时全部关闭。
- **按钮的红色**取自红笔，是页面里唯一的强调色，用于最重要的动作（保存）和当前所在位置。

## 调色板

| 名称 | 色值 | 用途 |
| :--- | :--- | :--- |
| 纸 `--paper` | `#f1ead9` | 页面底色 |
| 纸页 `--sheet` | `#fffdf6` | 卡片、表单 |
| 墨 `--ink` | `#1b2236` | 正文 |
| 封面 `--cover` | `#1f2a44` | 顶部封面条、当前步骤 |
| 红笔 `--red` | `#d0312d` | 强调、保存、错误原因 |
| 章绿 `--green` | `#2f7d4f` | 已掌握、正确答案 |
| 横线 `--rule` | `#cfe0ee` | 纸上的蓝色横线 |
| 边距 `--margin` | `#eaa29b` | 红色边距线 |
