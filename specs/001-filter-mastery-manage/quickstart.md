# Quickstart: 迭代 2 手动验证脚本

实现完成后，按下面的步骤在浏览器里走一遍，逐条对应 spec 的验收场景。手机尺寸（375px）和桌面各走一遍。

## 准备

```bash
cd frontend && npm run build
cd ../backend && STATIC_DIR=../frontend/dist uv run uvicorn app.main:create_app --factory --port 8000
```

打开 <http://127.0.0.1:8000>。先录入 6 道错题备用（可用 `OCR_ENGINE=fake` 加快）：

| # | 学科 | 内容（含关键字） | 标签 | 状态 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 数学 | 配方法求最值 | 函数、易错 | 未掌握 |
| 2 | 数学 | 解不等式 | 不等式 | 未掌握 |
| 3 | 英语 | She goes to the Library | 时态 | 未掌握 |
| 4 | 物理 | 答案里有"配方" | 函数 | 未掌握 |
| 5 | 数学 | 错误原因里有"配方" | 易错 | 未掌握 |
| 6 | 语文 | 100% 正确率_计算 | — | 未掌握 |

## 故事 1：筛选与搜索（US1）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 学科选"数学" | 只剩 #1、#2、#5，顶部"共 3 道" | US1-1 |
| 再选标签"函数" | 只剩 #1 | US1-2 |
| 清除，再依次选标签"函数"和"易错" | 只剩 #1（同时具备） | 边界：多标签交集 |
| 清除，选学科"数学" + 标签"易错" + 状态"未掌握" | 只剩 #1、#5（三个条件同时满足） | US1-3 |
| 清除，搜索"配方" | #1、#4、#5 都在 | US1-4 |
| 搜索 `LIBRARY` | #3（不区分英文大小写） | 边界 |
| 搜索 `%` | 只有 #6，不是全部 | 边界：特殊字符 |
| 搜索 `   `（全空格） | 等同没有关键字，全部显示 | 边界 |
| 数学 + 标签"函数" + 状态"已掌握" | 显示"没有符合条件的错题"和清除按钮，**不是**"本子还是空的" | US1-6 |
| 设置条件后点进一道题再返回；再刷新页面 | 条件都还在，地址栏带查询参数 | US1-7 |
| 录入超过一页（> 20 道）时点"加载更多" | 追加的仍符合条件，仍从新到旧 | US1-5 |

## 故事 2：掌握状态（US2）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 在列表里点 #2 的"标记已掌握" | 当场变成"已掌握"，不整页刷新、不跳转到详情 | US2-1 |
| 点进 #2 详情 | 也是"已掌握" | US2-2 |
| 详情里点"改回未掌握"，回到列表 | 一致地变回"未掌握" | US2-3 |
| 筛选"未掌握"，把其中一道标为已掌握 | 该题立刻从列表消失，总数减 1 | US2-4 |
| 停掉后端后点标记 | 提示失败，界面仍是原状态 | US2-5 |
| 重启应用，看 #2 | 仍是已掌握 | US2-6 |

## 故事 3：管理（US3）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 进"管理"页，新增学科"信息技术" | 立即出现；去录入页能选到 | US3-1 |
| 把"数学"改名为"高中数学" | 列表里原数学的题都显示新名 | US3-2 |
| 删除"语文"（有错题） | 被拒绝，提示"还有 1 道错题"，学科和错题都在 | US3-3 |
| 删除"信息技术"（空） | 消失，录入时也没了 | US3-4 |
| 把标签"函数"改名为"函数与方程" | 带它的题都显示新名 | US3-5 |
| 删除标签"易错"，确认 | 标签消失，#1、#5 仍在，只是不再带它 | US3-6 |
| 新增或改名成已有的名字；提交空白名称 | 分别提示"已存在""不能为空" | US3-7、US3-8 |
| 看管理页每一项 | 旁边有使用数 | US3-9 |
| 停掉后端后新增 | 提示失败，列表不变 | US3-10 |
| 先按标签"易错"筛选，再去管理页删掉这个标签，回到列表 | 提示该标签已不存在并清除这个条件，不报错 | 边界、FR-010 |
