# Quickstart: 迭代 2 手动验证脚本

实现完成后，按下面的步骤在浏览器里走一遍，逐条对应 spec 的验收场景。手机尺寸（375px）和桌面各走一遍。

## 准备

```bash
cd frontend && npm run build
cd ../backend && STATIC_DIR=../frontend/dist uv run uvicorn app.main:create_app --factory --port 8000
```

打开 <http://127.0.0.1:8000>。先录入 6 道错题备用（可用 `OCR_ENGINE=fake` 加快）：

| # | 学科 | 内容（含关键字） | 标签 | 掌握程度 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 数学 | 配方法求最值 | 函数、易错 | 一级 |
| 2 | 数学 | 解不等式 | 不等式 | 一级 |
| 3 | 英语 | She goes to the Library | 时态 | 一级 |
| 4 | 物理 | 答案里有"配方" | 函数 | 一级 |
| 5 | 数学 | 错误原因里有"配方" | 易错 | 一级 |
| 6 | 语文 | 100% 正确率_计算 | — | 一级 |

## 故事 1：筛选与搜索（US1）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 学科选"数学" | 只剩 #1、#2、#5，顶部"共 3 道" | US1-1 |
| 再选标签"函数" | 只剩 #1 | US1-2 |
| 清除，再依次选标签"函数"和"易错" | 只剩 #1（同时具备） | 边界：多标签交集 |
| 清除，选学科"数学" + 标签"易错" + 程度"≤二级" | 只剩 #1、#5（三个条件同时满足） | US1-3 |
| 清除，搜索"配方" | #1、#4、#5 都在 | US1-4 |
| 搜索 `LIBRARY` | #3（不区分英文大小写） | 边界 |
| 搜索 `%` | 只有 #6，不是全部 | 边界：特殊字符 |
| 搜索 `   `（全空格） | 等同没有关键字，全部显示 | 边界 |
| 程度选"最低三级"，再改为"最低二级、最高一级"（倒置） | 前者只剩后续调级后的题；后者显示"没有符合条件的错题"且不报错 | 边界：区间倒置 |
| 数学 + 标签"函数" + 程度"五级" | 显示"没有符合条件的错题"和清除按钮，**不是**"本子还是空的" | US1-6 |
| 设置条件后点进一道题再返回；再刷新页面 | 条件都还在，地址栏带查询参数 | US1-7 |
| 录入超过一页（> 20 道）时点"加载更多" | 追加的仍符合条件，仍从新到旧 | US1-5 |

## 故事 2：掌握程度分级（US2）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 在列表里点 #2 的掌握程度控件，选"三级" | 当场显示三级，不整页刷新、不跳转到详情 | US2-1 |
| 点进 #2 详情 | 也是三级 | US2-2 |
| 详情里把 #2 调到"四级" | 界面上出现掌握时间（当前时刻） | US2-3 |
| 详情里把 #2 降回"三级" | 掌握时间消失；再调回四级，掌握时间更新为这次时刻 | US2-4 |
| 筛选"≤二级"，把其中一道调为三级 | 该题立刻从列表消失，总数减 1 | US2-5 |
| 重复对同一题选同一个等级 | 等级不变，掌握时间不刷新 | 边界：幂等 |
| 停掉后端后调级 | 提示失败，界面仍是原等级 | US2-6 |
| 重启应用，看 #2 | 仍是四级，掌握时间不变 | US2-7 |

## 故事 3：编辑与清理（US3、US4）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 点进 #1 详情，点"编辑"，把内容改成"配方法求最值（已核对）"，保存 | 回到详情，显示新内容；回到列表卡片也是新内容 | US3-1 |
| 编辑 #1 把学科换成"英语" | 按"数学"筛选不再出现 #1；按"英语"筛选出现 | US3-2 |
| 编辑 #1 把标签换成"不等式" | #1 带"不等式"，不再带"函数" | US3-3 |
| 编辑时清空题目内容再保存 | 被拒绝并提示，原内容不变 | US3-4 |
| 把 #1 调到四级后点"删除"，在确认框里取消 | 题还在，无变化 | US4-1（确认环节） |
| 再次删除并确认 | 返回列表，#1 不再出现，总数减 1；"不等式"标签仍在 | US4-1、US4-4 |
| 对一道二级的题点"删除" | 被拒绝，提示"掌握程度达到四级后才能清理（当前：2 级）"，题还在 | US4-2 |
| 删除确认后（停掉后端模拟失败） | 提示失败，题仍在列表 | US4-3 |
| 总数超过 100 道时打开列表页 | 顶部出现"已超过 100 题，建议清理已熟练的题"提醒 | US4-5 |
| 按"≥四级"筛选并删除题，总数回到 100 以内 | 提醒消失 | US4-5 |

> 造数提示：101+ 题可用脚本直接往 SQLite 插入，或在录入页快速连录；删除场景用"≥四级"筛选批量处理。

## 故事 4：管理（US5）

| 步骤 | 预期 | 对应场景 |
| :--- | :--- | :--- |
| 进"管理"页，新增学科"信息技术" | 立即出现；去录入页能选到 | US5-1 |
| 把"数学"改名为"高中数学" | 列表里原数学的题都显示新名 | US5-2 |
| 删除"语文"（有错题） | 被拒绝，提示"还有 1 道错题"，学科和错题都在 | US5-3 |
| 删除"信息技术"（空） | 消失，录入时也没了 | US5-4 |
| 把标签"函数"改名为"函数与方程" | 带它的题都显示新名 | US5-5 |
| 删除标签"易错"，确认 | 标签消失，相关题仍在，只是不再带它 | US5-6 |
| 新增或改名成已有的名字；提交空白名称 | 分别提示"已存在""不能为空" | US5-7、US5-8 |
| 看管理页每一项 | 旁边有使用数 | US5-9 |
| 停掉后端后新增 | 提示失败，列表不变 | US5-10 |
| 先按标签"易错"筛选，再去管理页删掉这个标签，回到列表 | 提示该标签已不存在并清除这个条件，不报错 | 边界、FR-010 |
| 录入页学科下拉选"新增学科"，输入"化学" | 创建成功并自动选中；表单已填内容不丢；管理页和筛选栏也能看到"化学" | US5-11 |
| 录入时新增重名学科（如"数学"）或空白名称 | 分别提示"已存在""不能为空"，表单内容不变 | US5-12 |
